Qasim Sahito Academy — starter website

1. Open index.html in Chrome to test it.
2. Replace sample resource links (#) with your PDF URLs.
3. For a real public website, upload the folder to a hosting service such as GitHub Pages, Netlify, or Cloudflare Pages.
4. Important: HTML/CSS/JavaScript sent to a visitor's browser cannot be completely hidden. Never put passwords, API keys, or private admin credentials in this file.
5. For private editing and real PDF uploads, use a backend/CMS (for example Supabase/Firebase or a dedicated CMS). The public site can remain separate from the admin dashboard.
